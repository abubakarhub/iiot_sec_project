SecureIoT-Sim

A Smart Building simulated entirely in Python: 8 devices, a gateway and a cloud. We attacked it while it was insecure, secured it in four layers, then re-ran exactly the same attack code and measured the difference.

Architecture

Devices publish to an MQTT-style gateway; the cloud stores readings in SQLite and serves a REST API and dashboard. The attacker targets both the network path and the API. Everything runs on 127.0.0.1; the attack code refuses any other address.

Run it locally

The simulation needs a local machine (it runs a TCP broker and only talks to 127.0.0.1), so it cannot run on this website.

pip install -r requirements.txt
python main.py --compare
python main.py --mode secure --live
